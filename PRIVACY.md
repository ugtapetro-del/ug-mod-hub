# Privacy policy for the desktop client

UG MOD HUB connects to the project API to retrieve the signed catalog, request
selected files, check for program updates and authenticate a user account.

The desktop client may process an email address, nickname, session token,
application version, catalog version and technical error information needed to
complete these operations. Passwords are not stored by the client. Session
tokens and authorized IMG-key cache data are protected with Windows DPAPI.

The client does not intentionally collect game passwords, browser passwords,
documents, contacts or unrelated files. It only changes files selected by the
user inside the configured game directory and keeps backups needed to restore
them.

The public source repository contains no production database credentials,
SMTP passwords, signing private keys or game archive keys. The web service has
its own private configuration and access controls.

Questions or deletion requests should be sent through the contact method on
the official UG MOD HUB website.
