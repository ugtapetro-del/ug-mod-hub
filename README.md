# UG MOD HUB 0.1.6

> Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Локальний менеджер модів для UKRAINE GTA / MTA. Встановлює моди у потрібні папки гри, зберігає резервні копії замінених файлів та відновлює оригінали після видалення мода.

Під час запуску з сайту завантажується лише підписаний JSON-каталог. Файли окремого мода завантажуються тільки після натискання **«Встановити»**, перевіряються SHA-256 і зберігаються в локальному кеші для LIVE-захисту.

Додано дев’ять фірмових обкладинок розділів. Якщо мод не має власної PNG/JPG-обкладинки, картка автоматично використовує фон свого розділу; власне зображення завжди має пріоритет.

## Профіль користувача

Для входу потрібні нікнейм, електронна пошта та пароль. Після реєстрації застосунок дозволяє вхід лише після підтвердження пошти через одноразове посилання з листа. Пароль локально не зберігається; токен входу захищається Windows DPAPI.

Кнопка профілю розташована праворуч у верхній панелі. Старий розділ профілів збірок видалено.

## Використання

1. Запустіть `UG MOD HUB.exe`. Програма завжди запитує права адміністратора.
2. У **Налаштуваннях** виберіть папку `UKRAINEGTA` (ту, в якій розташована папка `game`).
3. Виберіть мод і натисніть **Встановити**.
4. Для входу використовуйте **Автопідключення** — програма запускає офіційний `UKRAINE GTA.exe`, а не `gta_sa.exe` напряму.

Другий екземпляр програми не запускається: якщо UG MOD HUB уже відкритий, Windows покаже відповідне повідомлення. У **Налаштуваннях** доступна кнопка автозапуску разом із Windows. Для автозапуску створюється завдання з найвищими правами.

Клієнт підключається до API через прямий origin `http://149.50.111.56:20069`, оскільки Cloudflare блокує запити EXE перевіркою браузера. Незашифрований HTTP дозволено лише для цього точного IP і порту. Ключ цифрового підпису закріплений SHA-256-відбитком, а каталоги, моди й оновлення додатково перевіряються цифровим підписом та SHA-256.

Інтерфейс використовує адаптивну сітку без великих проміжків: залежно від ширини вікна показується від однієї до чотирьох щільних колонок. Кінематографічний стартовий reactor-loader містить частинки, орбіти, сканер, еквалайзер і живий прогрес; головний банер, світлова лінія шапки та картки модів також мають багатошарові анімації. Режими **Повні**, **Спрощені** та **Вимкнені** керують навантаженням ефектів.

Назви IMG-шаблонів `GTA3`, `gta3.img`, `PEDS.img` та `acs.img` автоматично нормалізуються, тому різний регістр або службові символи у веб-каталозі не блокують запуск.

Профіль застосунку показує точну дату реєстрації користувача, яку повертає захищений account API.

Форма створення профілю автоматично збільшує висоту вікна, щоб кнопка реєстрації не обрізалася на екранах із невеликою висотою.

Після автооновлення новий EXE не успадковує тимчасову папку `_MEI` попереднього процесу, тому `python312.dll` завантажується зі свого runtime.

У публічному релізі 0.1.6 безрамкове головне вікно реєструється у Windows як звичайний застосунок: його кнопка відображається активною на панелі завдань, а згортання і відновлення працюють через системний механізм без прихованого зависання у фоні.

Фінальна папка 0.1.6 містить автономні Python 3.12, Tcl/Tk, OpenSSL, Visual C++ runtime та всі бібліотеки застосунку. Python, Microsoft Visual C++ Redistributable й сторонні драйвери встановлювати не потрібно. Файли модів у клієнт не вбудовуються: після запуску завантажуються підписаний каталог і легкі обкладинки, а потрібний payload — лише після натискання **«Встановити»**.

Доступний окремий розділ **Скіни**. Після натискання **Встановити** виберіть стандартний скін лише за його звичайною назвою. Програма використовує дані `ShSkin.lua` і `peds.ide`, не редагує IDE, автоматично знаходить потрібний зашифрований `PEDS.img` або `gta3.img`, вносить заміну та шифрує архів назад. Перед публікацією результат повторно відкривається і перевіряється; при помилці робочий архів гри не змінюється.

Кілька замін в одному IMG накопичуються. Видалення однієї заміни перебудовує архів із рештою встановлених скінів, а видалення останньої повертає резервну копію оригінального зашифрованого архіву.

Розділ **Аксесуари** працює за зв’язкою `ShAccessories.lua` → `acs.ide` → `acs.img`. Вбудований індекс зберігає точні MODEL ID, ShAccessories ID та назви DFF/TXD. Програма працює безпосередньо із зашифрованим ігровим архівом `game/bin/data/maps/ACS/acs.img`; перед першою заміною він зберігається в резервну копію. Якщо потрібного спільного TXD в архіві немає, його можна безпечно додати під час перебудови.

Якщо два аксесуари використовують спільний TXD, програма показує конфлікт і пропонує прибрати попередню заміну. Це запобігає непомітному пошкодженню текстур інших аксесуарів.

Розділ **Заміна зброї** містить 43 стандартні цілі. У застосунку показуються лише звичайні назви зброї, без ID, DFF і TXD. Після вибору цілі програма автоматично замінює потрібну пару DFF/TXD у зашифрованому `gta3.img`, зберігає решту встановлених замін і створює резервну копію оригінального архіву.

Ключі IMG не вбудовані в EXE і не лежать відкритим файлом біля програми. Після входу підтвердженого користувача вони коротко отримуються із захищеного API та кешуються локально через Windows DPAPI. Вихід із профілю або недійсний токен очищає цей кеш.

Поле в боковому меню шукає моди в реальному часі за назвою, описом, ідентифікатором або розділом. Клавіша `Esc` очищає пошук.

## Захист файлів

Фонова SHA-256 перевірка працює тільки для:

- **Кров + звук влучання**
- **Приціл**
- **HUD**

Якщо сервер видалить або змінить встановлений файл із цих розділів, менеджер відновить його з еталонної копії. Еталонний SHA-256 запам’ятовується під час встановлення. LIVE-захист працює і під час підключення до сервера; ручне встановлення та видалення модів при запущеній грі залишається заблокованим.

## DEV

У DEV-збірці:

1. Натисніть **Вибрати папку** та вкажіть папку одного мода. За бажанням виберіть власну PNG/JPG-обкладинку.
2. Перевірте назву, розділ і шлях призначення.
3. Натисніть **Додати в бібліотеку**.

DEV-моди зберігаються в `%LOCALAPPDATA%\MTAModHub\mods`. Цілком папку `deathmatch/resources` додавати не можна — обирайте папку конкретного мода.

У бібліотеці та DEV-списку показуються лише моди, для яких уже додані файли. Кнопка **Редагувати** дозволяє змінити параметри мода; якщо нову папку не вибирати, його поточні файли залишаться без змін.

## Можливості 0.1.6

- Новий інтерфейс **Nightline Hub** із компактною вертикальною навігацією, фірмовими зображеннями та нижньою панеллю запуску.
- Центральна область головної сторінки отримала наскрізний фон із трамваєм; службові панелі та картки залишаються контрастними поверх нього.
- Кнопка **«Грати в UKRAINE GTA»** відкриває мінісписок усіх відомих серверів; після вибору виконується штатна SHA-256 перевірка файлів і лише потім запускається гра.

- Каталог більше не блокує стартовий loader: після перевірки вебсервера застосунок одразу відкриває збережений список і тихо оновлює його у фоні.
- Тимчасовий таймаут повторюється автоматично без вікна помилки та без повторних натискань користувача.

- Перевірка підписаного релізу програми через приватний сайт.
- Завантаження EXE з перевіркою SHA-256 та безпечна заміна після закриття клієнта.

- Підтримка підписаних RSA-SHA256 каталогів із сайту на OpenSSL без залежності від Sodium.
- Зворотна сумісність із каталогами Ed25519.

- Компактний округлений лічильник FPS перенесено ближче до правого нижнього кута.

- Адаптивний розмір вікна за робочою областю Windows: застосунок більше не виходить за нижню межу екрана 1366×768.
- Повний, компактний та вузький режими верхньої панелі й бокового меню.
- Підтримка Windows DPI та різного масштабування на кількох моніторах.
- Адаптивні відступи сторінок і перебудова полів DEV на вузьких екранах.

- обране, історія дій і власні обкладинки модів;
- передстартова перевірка папки, файлів, конфліктів, процесів і місця на диску;
- повне відновлення чистої гри з резервних копій;
- окреме вікно операції зі швидкістю, поточним файлом, відсотком, часом і безпечним скасуванням;
- підписаний онлайн-каталог Ed25519 із SHA-256 перевіркою кожного файла, без ZIP;
- режими анімацій **Повні**, **Спрощені** та **Вимкнені**.
- LIVE-хеш-захист, який повертає еталонні файли після серверного перезапису навіть під час роботи MTA.
- повна SHA-256 перевірка всіх файлів усіх установлених модів перед автопідключенням із автоматичним відновленням і запуском гри лише після успішного завершення.
- перемикач реального FPS-лічильника в налаштуваннях із відображенням у правому нижньому куті.
- анімований стартовий loader із логотипом UKRAINE GTA та плавною появою головного вікна.
- власна темна панель вікна без стандартної білої рамки Windows, із кнопками згортання, максимізації та закриття.

Для вимірювання FPS використовується офіційний Intel PresentMon 2.5.1. Його ліцензія включена у папку `tools`.

## Збірка

DEV-збірка:

```powershell
.\build.ps1 -DistRoot .\release_audio
```

Закритий реліз без DEV:

```powershell
.\build.ps1 -DistRoot .\release_audio -ReleaseMode
```

Скрипт створює окремі версійні папки. ZIP-архіви не створюються.
